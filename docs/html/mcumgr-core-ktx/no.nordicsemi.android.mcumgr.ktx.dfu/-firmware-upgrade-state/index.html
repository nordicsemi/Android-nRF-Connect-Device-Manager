FirmwareUpgradeState

sealed interface FirmwareUpgradeState<out S : Enum<*>>

The state of a firmware upgrade, as reported by the flow returned by the upgrade methods of FirmwareUpgradeManagerKtx and SUITUpgradeManagerKtx.

The flow is cold: the upgrade starts when the flow is collected, and is cancelled when the collection is cancelled. The first emitted state is always Started. The flow completes after Completed or Cancelled, and fails with a FirmwareUpgradeException if the upgrade fails.

Type Parameters

S

The type of the state of the upgrade process, which is FirmwareUpgradeManager.State or SUITUpgradeManager.State.
