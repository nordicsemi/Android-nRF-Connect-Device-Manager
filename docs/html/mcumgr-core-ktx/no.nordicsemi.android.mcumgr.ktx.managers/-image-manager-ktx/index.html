ImageManagerKtx

class ImageManagerKtx(val manager: ImageManager)

A manager of the Image group of Mcu Manager, with suspending methods and flows. It wraps ImageManager.

Every suspending method waits until the response is received, and throws a McuMgrException if the request fails, or a McuMgrErrorException if the device responds with an error, that is with a non-zero return code. Cancelling the calling coroutine stops waiting for the response, but does not cancel the request, which has already been sent.

The upload and the download are long-running, and report their state using a Flow. See TransferState. To update the firmware of a device, with all the steps it takes, use no.nordicsemi.android.mcumgr.ktx.dfu.FirmwareUpgradeManagerKtx.

Use the manager to set a logger, the upload MTU, etc.
