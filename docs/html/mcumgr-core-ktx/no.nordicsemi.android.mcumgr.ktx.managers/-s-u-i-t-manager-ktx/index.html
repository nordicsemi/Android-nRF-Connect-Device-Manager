SUITManagerKtx

class SUITManagerKtx(val manager: SUITManager)

A manager of the SUIT group of Mcu Manager, with suspending methods. It wraps SUITManager.

These are the single requests of the group. Use no.nordicsemi.android.mcumgr.ktx.dfu.SUITUpgradeManagerKtx to perform the whole SUIT upgrade.

Every method suspends until the response is received, and throws a McuMgrException if the request fails, or a McuMgrErrorException if the device responds with an error, that is with a non-zero return code. Cancelling the calling coroutine stops waiting for the response, but does not cancel the request, which has already been sent.

Use the manager to set a logger, the upload MTU, etc.
